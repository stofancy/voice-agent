  - `message_router.py` 传递 `session.connection_state` 给 `VoiceTurn`
  - 移除 `VoiceTurn.handle_interrupt()` 死代码
- ~~确保状态转移的原子性和一致性~~ ✅

**测试覆盖**: 新增 22 个单元测试（`tests/unit/test_voice_turn.py`）
- ConnectionStateMachine 转移测试

**状态**: ✅ 已完成（2026-03-23）

### Step 3: 指标计算 + 密钥竞态修复

**问题**: StreamingSynthesis 指标计算使用错误变量；dashscope.api_key 全局竞态
**严重度**: 🔴 Critical
**涉及文件**: `src/server/streaming_synthesis.py`, `src/server/tts/bailian_tts_realtime.py`

**方案要点**:
- ~~修复 `llm_ttft_ms` 和 `llm_gen_ms` 计算（`t_llm_first - t_start` 而非 `t_llm_first - t_llm_end`）~~ ✅
  - `llm_ttft_ms`: `(t_llm_first - t_start) * 1000`（LLM 首 token 延迟）
  - `tts_ttfa_ms`: `(t_tts_first - t_llm_first) * 1000`（从首个 LLM token 到首个 TTS 音频）
  - `llm_gen_ms`: 不变，`(t_llm_end - t_llm_first) * 1000`
- ~~消除 `dashscope.api_key` 全局赋值，改为实例级 API key 传递~~ ✅
  - 移除 `dashscope.api_key = self._api_key` 全局赋值
  - 改为 `self._tts.apikey = self._api_key` 实例级赋值

**状态**: ✅ 已完成（2026-03-23）
