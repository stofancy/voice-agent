## ⚠️ 风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |

## 📝 开发规范

### 代码规范

- 使用 ESLint + Prettier
- 遵循 Airbnb JavaScript 风格指南
- 组件化开发（每个组件独立文件）

### Git 规范

```bash
# Commit message 格式
feat: 新增功能
fix: 修复 bug
docs: 文档更新
style: 代码格式
refactor: 重构
test: 测试
chore: 构建/工具

# 示例
git commit -m "feat(v2): 添加 VAD 语音检测功能"
```

### 分支管理

```
main (v1.0 稳定版)
  └── feature/v2-development (v2.0 开发分支)
        └── feature/vad-integration (功能分支)
        └── feature/interrupt-button (功能分支)
```
