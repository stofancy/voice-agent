## 2. 模型选型

### 2.1 语音识别 (STT)

**推荐模型**: `qwen3-asr-flash`

| 特性 | 说明 |
|------|------|
| **适用场景** | 短音频（最长 5 分钟）同步/流式识别 |
| **延迟** | 低延迟，适合实时交互 |
| **输入限制** | 文件大小 ≤ 10MB，时长 ≤ 5 分钟 |
| **支持语种** | 中文（普通话 + 方言）、英语、日语、韩语等 |
| **情感识别** | 支持 7 种情感（惊讶、平静、愉快、悲伤、厌恶、愤怒、恐惧） |
| **ITN** | 支持逆文本标准化（中文/英文） |

**API 接入方式**:
- OpenAI 兼容模式（推荐）
- DashScope 同步调用

**部署地域**:
- 中国内地：北京 `https://dashscope.aliyuncs.com/compatible-mode/v1`
- 国际：新加坡 `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`

### 2.2 语音合成 (TTS)

**推荐模型**: `qwen3-tts-instruct-flash`

| 特性 | 说明 |
|------|------|
| **适用场景** | 情感化内容生产，需要指令控制 |
| **流式输出** | 支持，可边合成边播放 |
| **指令控制** | 支持自然语言指令控制语音表现力 |
| **支持语种** | 中文、英文、日文、韩文、法文、德文等 |
| **音色** | 多种系统音色可选（Cherry, Chelsie 等） |

**API 接入方式**:
- DashScope 同步调用
- DashScope 流式调用

**部署地域**:
- 中国内地：北京 `https://dashscope.aliyuncs.com/api/v1`
- 国际：新加坡 `https://dashscope-intl.aliyuncs.com/api/v1`

## 3. API 调用方式

### 3.1 STT API 示例 (OpenAI 兼容模式)

```python
from openai import OpenAI
import os

client = OpenAI(
    api_key=os.getenv("DASHSCOPE_API_KEY"),
    base_url="https://dashscope.aliyuncs.com/compatible-mode/v1"
)

# 非流式
completion = client.chat.completions.create(
    model="qwen3-asr-flash",
    messages=[{
        "role": "user",
        "content": [{
            "type": "input_audio",
            "input_audio": {
                "data": "https://example.com/audio.mp3"  # 或 base64 data URL
            }
        }]
    }],
    stream=False,
    extra_body={
        "asr_options": {
            "enable_itn": False
        }
    }
)

print(completion.choices[0].message.content)
```

### 3.2 TTS API 示例 (DashScope)

```python
import dashscope
import os

dashscope.base_http_api_url = 'https://dashscope.aliyuncs.com/api/v1'

# 非流式
response = dashscope.MultiModalConversation.call(
    api_key=os.getenv("DASHSCOPE_API_KEY"),
    model="qwen3-tts-instruct-flash",
    text="你好，我是语音助手",
    voice="Cherry",
    language_type="Chinese",
    instructions='语速适中，语气友好',
    optimize_instructions=True,
    stream=False
)

audio_url = response.output.audio.url
```

### 3.3 TTS 流式示例

```python
response = dashscope.MultiModalConversation.call(
    api_key=os.getenv("DASHSCOPE_API_KEY"),
    model="qwen3-tts-instruct-flash",
    text="你好，我是语音助手",
    voice="Cherry",
    stream=True
)

for chunk in response:
    if chunk.output.audio.data:
        # Base64 音频数据，可直接播放
        play_audio(chunk.output.audio.data)
```

## 4. 关键特性

### 4.1 STT 关键特性

| 特性 | 说明 |
|------|------|
| **流式输出** | 支持，边识别边返回 |
| **情感识别** | 自动识别 7 种情感 |
| **语种检测** | 自动检测或手动指定 |
| **时间戳** | 句级和字级时间戳 |
| **ITN** | 逆文本标准化（数字、日期等） |

### 4.2 TTS 关键特性

| 特性 | 说明 |

| **指令控制** | 自然语言指令控制语调、语速、情感 |
| **多语种** | 支持 10+ 语种 |
| **音色** | 20+ 系统音色 |
| **采样率** | 最高 48kHz |

## 5. 限制与约束

### 5.1 STT 限制

| 限制项 | 值 |
|--------|-----|
| 文件大小 | ≤ 10MB |
| 时长 | ≤ 5 分钟 |
| 并发 | 取决于 API Key 配额 |
| 音频格式 | WAV, MP3, FLAC, AAC 等 |

### 5.2 TTS 限制

| 限制项 | 值 |
|--------|-----|
| 文本长度 | ≤ 512 Token |
| 指令长度 | ≤ 1600 Token |
| 并发 | 取决于 API Key 配额 |

## 6. 计费信息

### 6.1 STT 计费

- 按音频时长计费
- 每秒音频 = 25 Token
- 不足 1 秒按 1 秒计算

### 6.2 TTS 计费

- `qwen3-tts-flash`: 按字符数计费
- `qwen3-tts-instruct-flash`: 按 Token 计费

## 7. 错误处理

### 7.1 常见错误码

| 错误码 | 说明 |
|--------|------|
| 400 | 请求参数错误 |
| 401 | 未授权（API Key 无效） |
| 404 | 资源未找到 |
| 429 | 请求频率超限 |
| 500 | 服务器内部错误 |

### 7.2 错误处理策略

1. **重试机制**: 对于 5xx 错误，实现指数退避重试
2. **降级策略**: STT/TTS 失败时降级为文本交互
3. **超时控制**: 设置合理的超时时间（建议 30s）

## 8. 开发建议

### 8.1 音频格式

- **STT 输入**: PCM 16kHz 16bit 单声道（推荐）
- **TTS 输出**: PCM 24kHz 16bit 单声道

### 8.2 流式处理

- STT 和 TTS 都支持流式
- 流式可降低端到端延迟
- 需要处理分块数据的拼接

### 8.3 网络优化

- 使用国内节点（北京）降低延迟
- 实现连接池复用
- 考虑 CDN 加速音频下载
