## 1. 系统概述

### 1.1 目标

为 OpenClaw 开发一个 Voice Agent Channel 插件，支持浏览器端语音交互，集成 OpenClaw Agent 能力。

### 1.2 核心功能

| 功能 | 说明 |
|------|------|
| 语音输入 | 浏览器麦克风采集，WebSocket 传输 |
| STT | 阿里百炼 `qwen3-asr-flash` 语音识别 |
| Agent | OpenClaw Agent 处理和回复 |
| TTS | 阿里百炼 `qwen3-tts-instruct-flash` 语音合成 |
| 语音输出 | 浏览器播放 TTS 音频 |

## 4. 接口设计

### 4.1 WebSocket 协议

#### 4.1.1 客户端 → 服务端

**音频数据**:
```typescript
interface AudioMessage {
  type: 'audio';
  data: {
    format: 'pcm';
    sampleRate: 16000;
    channels: 1;
    encoding: 'base64';
    payload: string;  // Base64 编码的 PCM 数据
  };
}
```

**控制消息**:
```typescript
interface ControlMessage {
  type: 'control';
  action: 'start' | 'stop' | 'interrupt' | 'ping';
  sessionId?: string;
}
```

#### 4.1.2 服务端 → 客户端

**STT 结果**:
```typescript
interface TranscriptMessage {
  type: 'transcript';
  data: {
    text: string;
    isFinal: boolean;
    confidence?: number;
    emotion?: 'neutral' | 'happy' | 'sad' | 'angry';
  };
}
```

**TTS 音频**:
```typescript
interface AudioOutputMessage {
  type: 'audio_output';
  data: {
    format: 'pcm';
    sampleRate: 24000;
    channels: 1;
    encoding: 'base64';
    payload: string;
    isChunk: boolean;  // 是否为流式分块
  };
}
```

**状态消息**:
```typescript
interface StatusMessage {
  type: 'status';
  state: 'listening' | 'processing' | 'speaking' | 'idle';
  sessionId: string;
}
```

### 4.2 STT API 调用

```typescript
interface STTRequest {
  model: 'qwen3-asr-flash';
  messages: [{
    role: 'user';
    content: [{
      type: 'input_audio';
      input_audio: {
        data: string;  // Base64 或 URL
      };
    }];
  }];
  stream: boolean;
  extra_body: {
    asr_options: {
      enable_itn: boolean;
      language?: string;
    };
  };
}
```

### 4.3 TTS API 调用

```typescript
interface TTSRequest {
  model: 'qwen3-tts-instruct-flash';
  input: {
    text: string;
    voice: string;  // e.g., 'Cherry'
    language_type: 'Chinese' | 'English';
    instructions?: string;
  };
  stream: boolean;
}
```

## 5. 核心流程

### 5.1 语音对话流程

```
1. 用户点击"开始说话"
   ↓
2. 浏览器采集音频（MediaRecorder）
   ↓
3. WebSocket 发送音频分块
   ↓
4. 服务端累积音频，检测 VAD
   ↓
5. 语音结束 → 调用 STT API
   ↓
6. STT 返回文本 → 发送到 OpenClaw Agent
   ↓
7. Agent 返回回复文本
   ↓
8. 调用 TTS API 合成音频
   ↓
9. WebSocket 返回音频分块
   ↓
10. 浏览器播放音频
```

### 5.2 会话状态机

```
┌─────────┐
│  IDLE   │
└────┬────┘
     │ start
     ▼
┌─────────┐
│LISTENING│◄────────────┐
└────┬────┘             │
     │ speech_end        │ new audio
     ▼                  │
┌─────────┐             │
│PROCESSING│            │
└────┬────┘             │
     │ stt_done         │
     ▼                  │
┌─────────┐             │
│RESPONDING│────────────┘
└────┬────┘  tts_done
     │
     ▼
┌─────────┐
│COMPLETE │
└─────────┘
```

## 7. 配置设计

### 7.1 OpenClaw 配置

```json5
{
  plugins: {
    entries: {
      "voice-agent": {
        enabled: true,
        config: {
          serve: {
            port: 8765,
            path: "/voice-agent/stream",
          },
          bailian: {
            apiKey: "sk-xxx",
            sttModel: "qwen3-asr-flash",
            ttsModel: "qwen3-tts-instruct-flash",
            ttsVoice: "Cherry",
          },
          audio: {
            inputSampleRate: 16000,
            outputSampleRate: 24000,
          },
          session: {
            maxDurationMs: 300000,
            idleTimeoutMs: 30000,
          },
          security: {
            pairingRequired: true,
          },
        },
      },
    },
  },
}
```

### 7.2 环境变量

```bash
# 百炼 API Key
ALI_BAILIAN_API_KEY=sk-your-api-key-here

# 可选：覆盖配置
VOICE_AGENT_PORT=8765
VOICE_AGENT_STT_MODEL=qwen3-asr-flash
VOICE_AGENT_TTS_MODEL=qwen3-tts-instruct-flash
```

## 8. 错误处理

### 8.1 错误分类

| 错误类型 | 处理策略 |
|----------|----------|
| **网络错误** | 自动重连（指数退避） |
| **API 错误** | 降级为文本交互，提示用户 |
| **音频错误** | 提示检查麦克风权限 |
| **会话超时** | 自动断开，提示重新连接 |

### 8.2 错误码设计

```typescript
enum ErrorCode {
  AUDIO_CAPTURE_FAILED = 1001,
  WEBSOCKET_CONNECTION_FAILED = 1002,
  STT_API_ERROR = 2001,
  TTS_API_ERROR = 2002,
  AGENT_TIMEOUT = 3001,
  SESSION_EXPIRED = 4001,
}
```
